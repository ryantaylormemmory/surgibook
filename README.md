# SurgiBook v3.3

Emergency Theatre Booking System for South African hospitals.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v3.4.19 + shadcn/ui
- react-router-dom
- recharts (statistics)
- lucide-react (icons)

## Features

- 32-hour shift sessions with PIN auth
- Screen auto-lock after 2 min inactivity
- Case booking, editing, completion, cancellation
- Priority levels (routine/urgent/emergency/life-threatening)
- ASA classification (I–V)
- Team chat (general, anaesthesia, surgery)
- In-app notifications
- Statistics dashboard
- CSV export
- Responsive design (mobile + desktop)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The `dist/` folder is deployed to a static hosting service.
